What is this?

A SaaS control plane plus per-Deployment data planes. Each Deployment is its own k3s namespace, its own Postgres database, and its own host nginx vhost. The control plane provisions Deployments; the data plane handles per-tenant traffic.

Install

From a fresh clone you need:

git clone https://github.com/omarss/saas.git
cd saas
make build           # builds bin/controlplane, bin/dataplane, bin/migrate, bin/saasctl
./bin/saasctl init   # 8-step bootstrap (see ADR 020)

saasctl init takes about ten minutes on a cold machine (most of which is docker pulling images). Re-running is idempotent; see ADR 020 for the details and the PKCE deferral note.

Tip. Open saasctl init --help for the full flag set. The wizard accepts --config init.yaml for unattended runs.
